# ADR 0019 — Atualização das rotações de Duelos S10–S12 (18/11/2026)

**Status:** incorporado ao pacote de homologação; não publicado.  
**Fonte:** capturas do jogo fornecidas em 18/11/2026.

## Decisão
Atualizar `SERIES_ROTATIONS` em `gbr-intelligence.js` com as pistas, voltas e focos visíveis nas capturas para S10, S11 e S12. Atualizar o payload estático do `_worker.js` para que a distribuição Worker contenha o mesmo arquivo. Manter histórico anterior sem sobrescrita.

## Dados não presumidos
As capturas não mostram clima. `weather` permanece `null`. Não são inferidos stints, chuva, pneus ou estratégia.

## Vigência
O contador observado (~13d23h em 18/11) sustenta uma janela aproximada de 14 dias. O catálogo foi marcado de 18/11 a 01/12/2026 inclusive; confirmar por nova captura quando a rotação mudar.

## Impacto
Somente catálogo estático e payload do Worker. Sem alteração de Supabase, RLS, login, garagem, APIs ou formato de dados persistidos. Reversível pela restauração dos arquivos anteriores do pacote.

## Homologação
ZIP atualizado para homologação. Testes automatizados não executados por solicitação do responsável. Cloudflare e GitHub não foram atualizados.
